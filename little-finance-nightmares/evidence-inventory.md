# 證據清單與強度

日期：2026-11-24。此清單供 DT 問題定義與 game-design 硬條件使用，不把外部教材指南當作本遊戲的成效證明。

| 證據 | 與本專案相關的內容 | 證據界線 |
| --- | --- | --- |
| 使用者需求 | 小學生、生活理財投資、兩關、各一互動、答對取鑰匙、每關得分、最後進步成果、Godot Web 與 Blender 3D | 已確認的專案需求；未指定年級或玩家測試情境 |
| [CFPB 國小金融教育課程檢核工具](https://files.consumerfinance.gov/f/documents/cfpb_youth-financial-education-curriculum-review-tool.pdf) | 存錢、花費選擇、預算及投資概念可作為課程內容 | 是課程檢核依據，不是對此遊戲有效性的測試 |
| [CFPB 國小教學指引](https://files.consumerfinance.gov/f/documents/cfpb_pedagogy_elementary-school_handout.pdf) | 生活化選擇、比較方案及重複練習適合國小教學 | 是教學建議，尚未觀察本專案玩家 |
| [EU／OECD 兒少金融能力框架](https://www.oecd.org/en/publications/financial-competence-framework-for-children-and-youth-in-the-european-union_bf059471-en.html) | 規劃管理財務、風險與報酬均屬兒少金融能力內容 | 框架跨年齡，需調整到國小程度 |
| [CFPB 四至五年級理財選擇教材](https://files.consumerfinance.gov/f/documents/cfpb_building_block_activities_understanding-our-money-choices_guide.pdf) | 四至五年級可討論花費、儲蓄與影響選擇的因素 | 支持初步年齡假設，不能替代本地教師核准 |
| 現有 Godot 原型與測試 | 自動流程測試通過；瀏覽器能完成兩關、顯示分數與成果 | `prototype_observation`，只證明功能流程，不證明學習或可用性 |

## 仍缺的證據

- 國小實際玩家或教師訪談／觀察。
- 同一能力的前後測或遷移題，才能用「進步」描述學習變化。
- 猜題、重試與提示依賴的真實使用資料。
- 目標裝置、網路情境及可讀性測試。
