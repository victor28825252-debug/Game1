# 需求與驗證對照

| 需求 | 實作 | 驗證 |
| --- | --- | --- |
| 小學生生活理財判斷 | 第一關預算與新情境遷移；第二關必要支出、投資風險與分散 | `godot/tests/test_flow.gd` 雙步驟流程；題目內容人工檢視 |
| 兩關各一互動單元 | 每關一張理財台卡片，內含兩個連續判斷 | Godot 流程測試、瀏覽器操作 |
| 解題才能取鑰匙 | 兩題均答對才顯示 Blender 3D 鑰匙旋轉圖示，取鑰匙後才可開門 | Godot 流程測試 |
| 各關得分 | HUD 即時顯示 100 分起，答錯扣 20、提示扣 10、最低 40 | Godot 流程測試 |
| 最後顯示進步成果 | 首次建立基準，重玩比較同一關與上次的分數 | Godot 流程測試；瀏覽器持久化檢查 |
| 可部署 GitHub 的網頁版 | Godot Web 匯出至 `docs/`，子路徑入口轉向 `docs/` | 本機 HTTP 瀏覽器、遠端 URL |

學習證據邊界：自動測試只驗證程式邏輯；尚未有目標年級學生的理解、可用性或學習遷移資料。
